# Sistema de Gestión y Seguimiento de Tickets de Soporte Técnico

Este proyecto consiste en una propuesta inicial para el desarrollo de una aplicación web construida con C# y Blazor, orientada a registrar, organizar y dar seguimiento a solicitudes de soporte técnico de TI.
